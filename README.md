# Sriram Kakumanu — personal website

Next.js App Router, React, TypeScript, custom CSS, MapLibre GL, and Motion. Read the local owner-supplied AGENTS.md and MASTER_BUILD_BRIEF.md before changes. The owner's latest requests override earlier visual and homepage direction in those documents.

## Current owner direction

Strava-inspired dark design: a dark street map fills every page (always dark, regardless of system setting), with orange routes drawn on it. Content sits in a dark panel over the map: a left column on desktop, a bottom sheet on mobile with a bottom tab bar. Heavy, cinematic motion: a plane that flies between destinations on the home page, self-drawing routes, a live GPS dot, and camera flights between pages and cities. All motion respects `prefers-reduced-motion`.

Inspired by Strava, not copied: Strava orange (`#fc4c02`) and layout patterns, but our own wordmark and icons, and never Strava's name or logo.

## Development

Node 24 and npm 11. From the repo root:

    npm ci --no-audit --no-fund
    npm run dev

`predev`, `prebuild`, and `prebuild:preview` copy MapLibre's worker module into `public/vendor/` (git-ignored); the map does not load without it.

## Routes and content

| Route | Page | Old URLs that redirect here |
| --- | --- | --- |
| `/` | Home: world map with a plane. Start, pick a destination, and the plane flies there and opens that section | |
| `/projects/` and `/projects/<id>/` | Projects | `/work/`, `/activities/<id>/` |
| `/experience/` | Experience: roles by city; hovering flies the map there | `/segments/` |
| `/activities/` | Activities: real Strava runs and hikes, plus photos (coming soon) | `/routes/`, `/explore/` |
| `/profile/` | Profile: bio, school, trophy case, gear, clubs, and contact (GitHub, email, LinkedIn) | `/about/`, `/contact/`, `/follow/` |

The home-page destinations (Projects → Austin, Experience → San Jose, Activities → Guatemala, Profile → Frisco) live in `destinations` in `content/site.ts`. The plane starts at Frisco and remembers where it last landed for the rest of the browser session.

Old URLs render a redirect page (meta refresh plus client redirect), because static hosting has no server redirects.

All copy lives in `content/site.ts`, sourced from the master brief and the owner's résumé. Fields marked `TODO` are placeholders; empty values are hidden on the site. Phone, email, and the résumé PDF are not published without owner approval.

Route geometry lives in `content/routes.json`, generated by `npm run routes` (`scripts/build-routes.mjs`). It snaps walking routes to real streets via the public OSRM foot router at routing.openstreetmap.de. Only regenerate when waypoints change; the site never calls the router at runtime. Pages pass only the routes they use to the browser.

Real Strava activities: `scripts/fetch-strava.mjs` runs before every dev server and build. It fetches recent activities with the `activity:read` scope (privacy zones already excluded), keeps only public ones with GPS, replaces any name containing a blocked word (drinking, profanity, slang or low-effort titles; see `BLOCKED_WORDS`) with a Strava-style default such as "Evening Run" (activities over 4 miles lead with their rounded distance, e.g. "5-mile Night Run"), trims 400 m off both ends of each route, and writes `content/strava.json` (git-ignored). The Activities page lists runs and hikes. Without credentials, or on any error, the site falls back to the generated routes and the build still succeeds. Credentials (`STRAVA_CLIENT_ID`, `STRAVA_CLIENT_SECRET`, `STRAVA_REFRESH_TOKEN`) live in GitHub Actions secrets and in `.env.local` (git-ignored); set or replace them with `npm run strava:auth`. The deploy workflow also runs daily at 12:00 UTC to pull new activities. Strava's API terms require "Powered by Strava" attribution wherever its data appears.

Map tiles come from OpenFreeMap (`positron` light, `dark` dark styles). No API key is required. Map data © OpenStreetMap contributors; the attribution control must stay visible.

Metrics come from the owner's résumé; phone, email, and unverified social accounts are omitted. Kudos are per-visitor (localStorage) and never show a fabricated count. No tracking is installed. Search indexing is on: `app/robots.ts` and `app/sitemap.ts` generate `robots.txt` and `sitemap.xml`, and redirect-only old URLs are marked noindex.

## GitHub Pages preview

`.github/workflows/preview-pages.yml` builds and deploys on pushes to main. Pages source is GitHub Actions. Reproduce the hosted build:

    npm run build:preview

Only `out/` is uploaded. `trailingSlash: true` generates route directories with index.html so direct links and refreshes work on Pages. The site is served at https://sriramkakumanu.com/ (custom domain set in the repo's Pages settings; DNS at GoDaddy points the apex at GitHub Pages' A records and `www` at `sriramk12.github.io`). Old `sriramk12.github.io/PersonalPortfolio/` links redirect there. `PREVIEW_BASE_PATH` is still supported for hosting under a subpath.
